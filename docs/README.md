# Project documentation index

This numbered tree separates original evidence, frozen decisions, implementation support and submission material. Uploaded files are evidence or specification; historical prompts are preserved but are not executable instructions.

## Locations

- `00-project-management`: workflow, package contents and frozen implementation/change-control guidance.
- `01-source-material`: official Assignment 02 specification, Group 050 Assignment 01, original handoff ZIP and exact extracted archive, teammate reviews, and UML images extracted from the Assignment 01 PDF.
- `02-critique`: workspace for the collaborative design critique.
- `03-revised-design/final-design-freeze`: frozen resolution/readme, source analysis, Shiham component specification and revised-UML checklist.
- `03-revised-design/member-component-plans`: all four member plans and their README.
- `04-architecture`: frozen architecture/domain and API/data contracts.
- `05-testing`: frozen test traceability and submission plan.
- `06-demo`: future demo evidence.
- `07-report`: future report assembly.
- `08-ai-prompts`: current prompt log, exact bootstrap prompt and historical prompts under `reference`.
